# 🎮 Tetris Mobile (Flutter)

Полноценная игра **Тетрис** для мобильных телефонов на **Flutter**, настроенная для автоматической сборки APK через **GitHub Actions** без необходимости устанавливать Android Studio!

---

## 🌟 Особенности игры

- 🧱 **Классическая механика Tetris**:
  - Все 7 классических фигур (тетромино: I, J, L, O, S, T, Z) с неоновой подсветкой и объёмным стилем.
  - Честный генератор фигур (**7-Bag Randomizer**).
  - **Проекция падения (Ghost Piece)** — полупрозрачная тень, показывающая, куда именно приземлится фигура.
  - **Super Rotation System (Wall Kicks)** — плавные повороты фигур даже вплотную к стенкам и блокам.
  - **Функция "Запас" (Hold Piece)** — возможность отложить текущую фигуру нажатием кнопки или тапом по окну "ЗАПАС".
  - **Сброс (Hard Drop)** — мгновенное падение фигуры вниз с начислением бонусных очков.
  - **Мягкое падение (Soft Drop)** — ускоренное падение при удержании стрелки вниз.
  - **Комбо и уровни** — начисление очков за одиночные, двойные, тройные линии и классический **ТЕТРИС** (4 линии), а также комбо-множители за последовательные очистки.
  - Рост уровня и ускорение игры каждые 10 очищенных линий.
  - Локальное сохранение **рекорда (High Score)**.
  - Визуальная анимация вспышки при сгорании линий.

- 📱 **Управление для телефонов (Mobile UX)**:
  - **Наэкранный геймпад для пальцев**:
    - Стрелки Влево / Вправо с поддержкой быстрого автоповтора (DAS — Delayed Auto Shift) при зажатии.
    - Мягкое падение (стрелка вниз) с автоповтором.
    - Большая кнопка поворота по часовой стрелке и кнопка поворота против часовой стрелки.
    - Кнопка мгновенного сброса (**СБРОС**).
  - **Жесты прямо по игровому полю**:
    - Тап по полю — поворот фигуры.
    - Свайп влево / вправо — перемещение.
    - Свайп вниз — ускоренное падение.
    - Быстрый резкий свайп вниз — мгновенный сброс (Hard Drop).
  - **Тактильная виброотдача (Haptic Feedback)** на телефоне при перемещениях, поворотах, сбросе и сгорании линий (можно включить/выключить кнопкой в шапке).
  - Защита от случайного выхода, пауза и диалог завершения игры с кнопкой "Играть снова".
  - Поддержка клавиатуры (стрелки, пробел, C, X, Z) при тестировании на ПК.

## 🚀 Как собрать APK через GitHub (без Android Studio)

В проекте уже настроен файл автосборки: [`.github/workflows/build_apk.yml`](.github/workflows/build_apk.yml).

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий (например, `tetris-mobile`), **без** добавления README, .gitignore и лицензии (репозиторий должен быть пустым).

### Шаг 2. Отправьте код в GitHub
Откройте терминал в папке проекта (`c:\Users\User\Desktop\tet`) и выполните команды:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/tetris-mobile.git
git add .
git commit -m "Initial Tetris Mobile commit"
git push -u origin main
```
*(Замените `ВАШ_ЛОГИН` и `tetris-mobile` на адрес вашего репозитория)*

### Шаг 3. Скачайте готовый APK
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Вы увидите запущенную сборку **Build Android APK**.
3. GitHub в облаке автоматически установит Flutter, Java, скомпилирует релизный APK (~2-3 минуты).
4. Когда появится зелёная галочка ✅:
   - Нажмите на этот запуск.
   - Внизу страницы в блоке **Artifacts** появится архив: **`tetris-release-apk`**.
   - Скачайте его на телефон или компьютер, распакуйте ZIP — внутри лежит файл `app-release.apk`!
5. Установите `app-release.apk` на телефон (при первом запуске разрешите установку из вашего проводника/браузера).

## 🛠 Локальное тестирование на ПК (при желании)

Если у вас установлен Flutter, игру можно запустить прямо на компьютере в режиме Windows или Chrome:
```bash
flutter run -d chrome
# или
flutter run -d windows
```
